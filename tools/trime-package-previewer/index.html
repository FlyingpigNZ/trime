Trime YAML Attribute Reference & Package Keyboard Previewer

Attributes consumed by the Trime app UI from self-contained IME package YAML files (Rime engine fields excluded).

How to read this reference

This is generated from the current Trime Android codebase: Theme, GeneralStyle, TextKeyboard, PresetKey, ToolBar, LiquidKeyboard, ColorManager, and the component resolver/loader. Fields listed here are actually read by the app. Unknown YAML keys are ignored unless they are dynamic palette color keys. Rime schema/dictionary/Lua/OpenCC attributes are intentionally excluded. Sections parsed by the resolver but not currently consumed by the UI (switches, keyboard_switch_policy, resources) are also excluded.
